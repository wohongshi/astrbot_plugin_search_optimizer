# 🔍 搜索结果优化器

AstrBot 插件 — 压缩搜索结果 + 缓存加速 + 并行处理，减少主力模型 Token 消耗。

## 功能

### 1. 搜索结果预处理
拦截搜索/抓取工具返回结果，压缩后再交给主力模型：
- **有预处理模型** → 用低成本 LLM 摘要压缩
- **无预处理模型** → 规则提取（去噪、去重、截断，零 LLM 调用）

### 2. 优化网络搜索（可选）
命中缓存时跳过搜索，直接注入上下文：
```
用户提问 → 检查缓存 → 命中 → 跳过搜索，直接回答
                     → 未命中 → 搜索 → 预处理 → 缓存 → 回答
```

### 3. LRU 缓存淘汰
缓存超过上限时自动淘汰命中次数最少 + 最久未用的条目，防止内存膨胀。

### 4. 多 URL 并行预处理
`web_fetch` 一次抓取多个页面时，并行调用预处理，速度更快。

## 配置（WebUI 插件管理）

| 配置项 | 说明 | 默认 |
|--------|------|------|
| **预处理模型** | 留空=规则提取 | 空 |
| **优化网络搜索** | 命中缓存时跳过搜索 | 关 |
| **缓存保留天数** | 1/3/7 天 | 3 |
| **缓存条目上限** | LRU 淘汰阈值 | 200 |
| **摘要最大字符数** | 控制压缩后长度 | 1500 |

## 指令

| 指令 | 说明 |
|------|------|
| `/搜索优化器` | 查看运行统计 |
| `/清除缓存` | 清空全部搜索缓存 |
